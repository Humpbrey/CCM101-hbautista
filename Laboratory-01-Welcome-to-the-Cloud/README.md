# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to a cloud-based Linux environment using KillerCoda. The activity focused on basic Linux commands, system information gathering, file and directory management, and documenting technical work using GitHub.

## Objectives

- Access and explore a cloud-based Linux environment.
- Learn and practice basic Linux terminal commands.
- Gather basic system information.
- Create and organize files and directories.
- Create and maintain a GitHub repository.
- Document the activities and results using Markdown.

## Activities Performed

- Accessed the Ubuntu Linux environment through KillerCoda.
- Created and configured a Linux user.
- Navigated the Linux file system using terminal commands.
- Gathered information about the Linux distribution, kernel, CPU, memory, and disk space.
- Created the required directory and file structure.
- Created a public GitHub repository for the Cloud Computing portfolio.
- Created and documented the laboratory files using Markdown.
- Captured screenshots as evidence of the completed activities.

## Linux Commands Used

- `whoami` – displays the current username.
- `pwd` – displays the current working directory.
- `hostname` – displays the hostname of the system.
- `adduser` – creates a new Linux user.
- `usermod` – modifies user account settings and group membership.
- `su` – switches to another user account.
- `mkdir` – creates directories.
- `cd` – changes the current directory.
- `cat` – displays the contents of a file.
- `uname` – displays system and kernel information.
- `lscpu` – displays CPU information.
- `free` – displays memory information.
- `df` – displays disk space information.
- `touch` – creates an empty file.

## Skills Learned

Through this laboratory activity, I learned how to work with a Linux terminal in a cloud-based environment. I practiced navigating directories, managing users, gathering system information, and creating files and folders. I also learned how to organize technical documentation using Markdown and maintain a Cloud Computing portfolio using GitHub.
